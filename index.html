01 · 它是什么

用 LLM 智能体完成「文献检索 → 结构化抽取 → 研究空白识别 → 假设生成 → 合成路线设计 → 证据回溯 → 对照验证」的全链路科学发现闭环。

解决的问题

硫银锗矿（argyrodite）Li₆PS₅Cl 是极具前景的固态电解质，但「高电导率 × 空气稳定性」难以兼得，跨文献工艺条件分散、难以横向比较。人工阅读海量文献找研究空白、设计合成路线，耗时且不可复现。

我们的方法

系统自主阅读 346 篇全文，结构化抽取为 346 条记录，识别 12 个 Research Gap、生成 13 条候选假设与 5 条合成路线；每条主张都锚定证据记录、可一键回溯原文；四臂对照协议量化「有证据/无证据断言」差异。

两层架构：数据 / 审计层（自研纯标准库）+ 编排层（AgentScope 2.0 自主发现循环）

09 · 复现与开源

运行时零重型依赖，数据 / 审计层为纯 Python 标准库，认知层唯一第三方运行时依赖为 AgentScope 2.0（Apache-2.0）。

一条命令复现评估

pip install -r requirements.txt
python -m agent.run --stage evaluate   # 输出 SHA 确定性一致
python -m agent.run --stage compare    # 四臂对照审计
python -m agent.run --stage discover --goal "…" --max-rounds 8

确定性保证

  • 随机种子：--seed 42（可复现）
  • 证据锚点：doc_id → record_id → 原文 JSON
  • 审计层零 LLM、零网络
  • 依赖披露：Sciverse / DeepSeek / Materials Project / AgentScope
