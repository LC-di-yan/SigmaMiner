02 / SYSTEM

它不是一个聊天窗口，而是一条发现流水线

用 LLM 智能体完成「文献检索 → 结构化抽取 → 研究空白识别 → 假设生成 → 合成路线设计 → 证据回溯 → 对照验证」的全链路科学发现闭环。

THE PROBLEM

跨文献工艺条件分散

硫银锗矿（argyrodite）Li₆PS₅Cl 具有高离子电导率潜力，但「高电导率 × 空气稳定性」难以兼得。组成、球磨、退火和测试条件散落在不同论文中，人工难以横向比较，也难以可靠找到研究空白。

THE APPROACH

让每个结论都带着证据

系统自主阅读全文，抽取为结构化记录，再基于证据组合识别 Gap、生成假设并设计路线。每条主张都锚定 record_id → doc_id → 原文，并用四臂协议审计路线质量。

两层架构：数据 / 审计层（自研纯标准库）+ 编排层（AgentScope 2.0 自主发现循环）

10 / REPRODUCE

复现与开源

运行时零重型依赖，数据 / 审计层为纯 Python 标准库，认知层唯一第三方运行时依赖为 AgentScope 2.0（Apache-2.0）。

一条命令复现评估

pip install -r requirements.txt
python -m agent.run --stage evaluate   # 输出 SHA 确定性一致
python -m agent.run --stage compare    # 四臂对照审计
python -m agent.run --stage discover --goal "…" --max-rounds 8
